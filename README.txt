HyperOS 2 Launcher — Redmi A5 Edition (prototipo)

Compatibilidad objetivo:
- Android 8.0+; probado conceptualmente para Android 15 Go Edition.
- Diseño inspirado en HyperOS, no es software oficial de Xiaomi.
- No sustituye el centro de control, pantalla de bloqueo ni paneles protegidos del sistema.
- No solicita permisos de accesibilidad, root ni administrador del dispositivo.

Cómo compilar el APK:
1. Instala Android Studio en un PC.
2. Abre esta carpeta como proyecto.
3. Permite que Gradle sincronice y descargue las herramientas.
4. Ve a Build > Build Bundle(s) / APK(s) > Build APK(s).
5. Instala el APK generado en app/build/outputs/apk/debug/app-debug.apk.
6. En el Redmi A5, abre Ajustes > Aplicaciones > Aplicaciones predeterminadas > Aplicación de inicio y selecciona HyperOS 2 Launcher.

Nota:
Este paquete contiene el código fuente del proyecto Android. No contiene un APK compilado porque este entorno no dispone del Android SDK/Gradle necesarios para producir y probar un APK real.
